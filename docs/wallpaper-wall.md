# 壁纸墙

访问 `/image`；Fuwari 导航会自动增加「壁纸墙」。在 `/admin` 的「壁纸墙」中管理设置，仅管理员可以修改。

默认使用 Lolicon 社区精选，备用 Pixiv 日榜，24 小时更新一次。首次保存设置会自动创建私有 `wallpaper_settings` 表，无需新环境变量或手动导入图片。现有 Appwrite 服务端密钥需要具备创建表与读写行的权限。

支持 Lolicon、Anosu、Pixiv 日榜/周榜/月榜/原创榜和精选与日榜混合模式。Anosu 适配已接入，但当前开发环境无法解析其域名，建议保留备用源。第三方源和图片代理的可用性会影响加载。

图片直接通过配置的 Pixiv 代理加载，Appwrite 只保存设置。每批作品共用缓存并合并并发请求；缓存使用项目现有机制：开发环境文件缓存，生产环境内存缓存，配置 Redis 后使用共享 Redis 缓存。生产环境未配置 Redis 时，服务重启或 serverless 冷启动后会重新获取作品，旧缓存不能跨实例保证保留。HTTP 响应另外有 5 分钟 CDN 缓存。

缓存未过期时不请求上游；过期后先重试主数据源，再使用备用源，两者都失败时返回仍存在的旧缓存。旧缓存保留最长 7 天。失败后有 1 分钟重试间隔。更改设置会使用新的缓存键。

日榜按最新榜单自动更新，社区精选按更新间隔随机重新选图，不等同于真正的每日排行榜。搜索与横竖屏筛选作用于已加载作品，滚动到底部加载下一批，每批及最大批数可配置。

作品会显示标题、作者与原作链接。服务端过滤年龄限制、额外屏蔽标签、AI 标记、漫画/动图类型和超长图片；社区年龄标记不等于 Pixiv 的分类，上游元数据也可能缺失，因此筛选不能保证全部内容分级准确。系统始终保留基础年龄标签过滤。

原图下载经本站接口返回附件，最多 25MB；只能下载当前缓存中的作品，不接受任意 URL。手机支持触摸缩放和切换，桌面支持键盘预览，工具栏包含旋转、下载及原作入口。

页面设计沿用 Fuwari 的字体、表面色和可调主题色，以图片为主要视觉，桌面四列、平板三列、手机两列。组件使用 `react-masonry-css` 和 `react-photo-view`，页面和后台设置分别放在独立模块中。

验证命令：

```sh
yarn jest __tests__/lib/wallpapers.test.js __tests__/lib/wallpapers-api.test.js __tests__/components/wallpaper-settings.test.js __tests__/components/wallpaper-wall.test.js --runInBand
```
