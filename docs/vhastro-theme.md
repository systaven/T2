# vhAstro 主题移植（第一阶段）

独立主题目录：`themes/vhastro`。以 [uxiaohan/vhAstro-Theme](https://github.com/uxiaohan/vhAstro-Theme) 的顶栏、头像横幅和卡片布局为基准，默认主题色改用 Fuwari 的 200° 天蓝色；不是运行 Astro，也不是迁移内容。

## 预览

启动项目的 `yarn dev`，访问 `/?theme=vhastro`。主题内部链接会保留预览参数，管理后台和外链中转页面不会带入它。直接访问不带参数的页面仍用原来配置的主题。本次没有修改默认主题。

SSG 页面不能按每个请求的查询参数生成不同 HTML，因此预览入口先接管默认主题的静态 HTML，再切换主题，可能短暂看到默认主题。正式设为默认后不需要这个切换。没有将页面改为服务端逐请求渲染。

## 已接入

- 首页、文章/Notion 页面、搜索结果、归档、分类、标签、404。
- 可配置左右位置的资料栏、现有 Notion 菜单及子菜单、名称/链接自动匹配 SVG 图标。未识别的菜单使用链接图标，不额外加入业务页面。
- 暗色模式，沿用项目原有的全局开关和存储。
- Clerk 原生登录和头像菜单，复用管理后台入口。未配置 Clerk 时不渲染；服务加载期间显示账号图标，15 秒未就绪提示重试。没有调整认证密钥或允许域名。
- 搜索弹窗、快捷键 Ctrl/Cmd+K、焦点限制、Esc 关闭、现有搜索路由、加载和失败状态。搜索不是新的数据库/全文检索服务；正文匹配仍取决于现有索引。
- 原生评论及其他已配置的评论选项；Notion `comment: Hide` 不挂载评论，未解锁时不挂载评论。
- 密码和登录锁、受现有路由截断的部分公开正文、链接悬浮预览、非白名单外链中转、正文目录。
- 封面加载失败时，文章卡片显示分类占位，文章头图自动收起；移动导航支持点击外部/焦点离开关闭，Esc 关闭后焦点返回按钮。
- 正文宽表格、代码块在自身容器内横向滚动；暗色代码高亮、引用和提示块使用主题内的可读配色，目录锚点避开固定顶栏。没有修改全局 Notion 样式。
- 复用已有音频组件，映射局部颜色变量，接入时不加载 Fuwari 布局/样式。播放器客户端按需加载，不再等待进入视口；不与通用悬浮播放器重复。vhAstro 的播放器总开关默认与 Fuwari 一致，避免预览配置加载后变成关闭。未额外设置歌单或曲目。
- 一言侧栏卡片，读取 `v1.hitokoto.cn`，按 UTC 日期在浏览器每日缓存，并合并同一时刻的请求；8 秒超时和失败重试，不读写 Appwrite。
- 首页横幅增加轻量气泡粒子，离开视口或切到后台标签时暂停；头像悬停旋转 18.88°。搜索通过现有 Headless UI 提供打开及关闭过渡；文章导航使用浏览器动画，不延迟路由、不重挂载播放器，失败导航恢复可见状态。系统减少动态效果时关闭这些动效。
- 文章目录放在侧栏所有组件之后，桌面滚动时吸附在顶栏下方，目录内部独立滚动；手机端保持正常流布局，避免遮挡正文。

字体沿用仓库目前已分包的 Maruko Gothic SC；没有替换/下载字体。文章、评论、搜索弹窗和音频组件按需加载。

图标字体修复：`fa-brands-400.woff2` 和 `fa-solid-900.woff2` 原文件无法正常解码，已使用仓库中同版本的 TTF 重新压缩，并给对应 CSS 字体网址增加版本参数以避开旧缓存。24 份本地 WOFF2 均已通过字体解码检查；正文分包不变。

### 验证码控制台问题

评论验证码已增加失败/超时提示与手动重试，脚本加载失败后允许重新载入，不再自动反复启动失败挑战；服务端验证没有取消或降级。

`Cannot determine Turnstile's embedded location` 以及对应 clearance 请求失败，需要检查 Cloudflare 小组件的 Pre-clearance 设置。这不是评论验证的必需功能；仅验证评论时关闭预通行即可。确实需要预通行时，需按 [官方说明](https://developers.cloudflare.com/turnstile/additional-configuration/hostname-management/pre-clearance/) 对齐已注册的 Cloudflare Zone、WAF 和组件允许域名。此次没有代改外部服务设置。

`flexible?lang=auto` 内的沙箱脚本、Windows WebGPU `powerPreference` 和无可用 adapter 信息来自第三方验证码框架，不是本站粒子动画（粒子只使用 CSS）。不修改第三方 iframe 的沙箱安全权限，也不屏蔽整个浏览器控制台。不能把本地 Linux 浏览器的测试当成用户 Windows 环境的完全复现。

## 可选设置

默认直接读取现有站点封面、头像、作者和简介，无需改 Notion 数据结构。`themes/vhastro/config.js` 提供以下可选项：

| 配置                       | 默认      | 作用                                                                    |
| -------------------------- | --------- | ----------------------------------------------------------------------- |
| `VHASTRO_HOME_BANNER`      | 空        | 空时优先站点 Notion 封面，再使用本地 `/bg_image.jpg`                    |
| `VHASTRO_SIDEBAR_POSITION` | `right`   | 桌面侧栏 `left` / `right`；手机始终先正文后侧栏                         |
| `VHASTRO_HITOKOTO`         | `true`    | 侧栏一言开关                                                            |
| `VHASTRO_ARTICLE_COMMENT`  | `true`    | 总评论开关；不能覆盖单篇 Notion 的 Hide                                 |
| `VHASTRO_MUSIC`            | `true`    | 主题播放器开关；仍需全局 `MUSIC_PLAYER` 开启                            |
| `MUSIC_PLAYER`             | `true`    | vhAstro 播放器总开关；Notion 或 `NEXT_PUBLIC_MUSIC_PLAYER=false` 可关闭 |
| `VHASTRO_THEME_COLOR`      | `#3aa8df` | Fuwari 天蓝色，可通过 `NEXT_PUBLIC_VHASTRO_THEME_COLOR` 环境变量配置    |

例如在 `.env.local`（或部署平台的环境变量设置）中填写：

```dotenv
NEXT_PUBLIC_VHASTRO_THEME_COLOR="#a855f7"
```

支持 `#RGB` / `#RRGGBB` 十六进制颜色，建议加引号，避免 `#` 被当成注释。无效值回退到默认天蓝色（`#3aa8df`）；暗色模式使用中性灰背景、卡片与边框，默认强调色降饱和为 `#82b6d0`，浅色文字链接适当加深以保证可读性。自定义色会同步到导航、标签、搜索弹窗、评论和音乐播放器，并自动派生浅色/暗色模式下可读的强调色和按钮文字颜色。不提供调色控件，不需要改数据库或 Notion 菜单。

侧栏原版在右侧，保留此默认；修改 `themes/vhastro/config.js` 的 `VHASTRO_SIDEBAR_POSITION: 'left'`，或设置 `NEXT_PUBLIC_VHASTRO_SIDEBAR_POSITION=left` 即可换到左侧。小屏幕自动恢复正文在前的单列布局，不更改 Notion 菜单。

修改后本地重启开发服务；生产环境需要重新构建并部署，因为 `NEXT_PUBLIC_` 配置会写入前端构建产物。
